MFFMv14 — Universal Android Font Module Builder
Version: 2026.08.08

Build flashable font modules for Magisk, KernelSU, APatch, and Mountify
from any static or variable font family — on PC or directly from Termux.

━━━━━━━━━━━━━━━━━━━━━━
What's New
━━━━━━━━━━━━━━━━━━━━━━

OS/2 Binary Weight Detection
No more filename guessing. Weight and style are now read directly from each
font's OS/2 table — any filename works, including Android hex cache names
like 61555016c4027e1b-s.p.ttf.

Serif & Monospace TTC Bundler
Multi-weight static Serif and Monospace families in /sdcard/MFFM/ are now
auto-bundled into a single indexed TTC, just like Bengali. Only weights
actually present are written to the XML.

Bengali TTC Fix
Critical bug fixed — the TTC bundler was receiving all paths as one string
instead of separate arguments, causing it to silently fail. All Bengali
weight faces now bundle correctly.

Highlights
━━━━━━━━━━━━━━━━━━━━━━

- Single TTC packs all weight faces (100–900 + Italic)
- Supports Sans, Serif, Monospace, Bengali independently
- Auto-installs fontTools via Termux pip if missing during flash
- Variable font fvar axis detection and live .conf axis tuning
- OpenType feature freezing per family (ss01, zero, tnum...)
- Centered colon injection for lockscreen clock digits
- Patches fonts.xml, font_fallback.xml and Pixel fonts_customization.xml
- Full POSIX sh — mksh, busybox ash, all Android shells supported
- Full set -x debug log saved to /sdcard/MFFM/

━━━━━━━━━━━━━━━━━━━━━━
Fallback (no Termux / no fontTools)
━━━━━━━━━━━━━━━━━━━━━━

Bengali   → 3 files  (Regular / Medium / Bold)
Serif     → 4 files  (Regular / Italic / Bold / BoldItalic)
Monospace → 1 file   (Regular only)
Variable  → always works, no fontTools needed

Quick Start
━━━━━━━━━━━━━━━━━━━━━━

PC:
  1. pip install -r requirements.txt
  2. Put fonts in Fonts/Sans/ (mandatory)
  3. python build.py
  4. Flash dist/*.zip in Magisk / KernelSU / APatch

Termux (on-device):
  1. unzip MFFMv14-Source-Template.zip -d ~/MFFMv14
  2. cd ~/MFFMv14
  3. sh termux-build.sh

External fonts after flash — drop files and reflash:
  /sdcard/MFFM/Bengali/
  /sdcard/MFFM/Serif/
  /sdcard/MFFM/Monospace/
  Any filename accepted. Weight auto-detected from font binary.
