MFFMv14 -- Universal Magisk, KernelSU & APatch Font Module Builder

Automated tool & template to build flashable Android font modules for Magisk, KernelSU, APatch, and Mountify/OverlayFS.

Highlights & Capabilities:
- On-Device Termux Automation (termux-build.sh): Build & auto-flash with 1 command.
- Flexible Family Support: Build Sans-only, Bengali-only, Serif-only, or Monospace-only modules.
- Single TTC Container (DroidSans.ttf): Packs all faces into one TTC file with dynamic system XML patching.
- Bengali 100-900 Weight Engine: Full weight class support (Thin to Black) & --bengali-features.
- OpenType Feature Freezer: Interactive or flag-based feature freezing (ss01-ss20, zero, tnum, etc.).
- Centered Colon (:): Automatic contextual digit colon injection for lockscreen clocks (12:30).
- /sdcard/MFFM/ Subdirectories: Auto-creates Sans/, Serif/, Monospace/, Bengali/ fallback folders.
- Native Variable Font Parsing: Natively extracts fvar variation axes in recovery without custom scripts.
- Smart Config & Auto-Pruning: Live .conf axis tuning in /sdcard/MFFM/. Auto-prunes obsolete config keys.
- Pixel & Product Patching: Patches fonts.xml, font_fallback.xml, and product fonts_customization.xml.
- Cryptographic Signing: Auto-signs output ZIPs using built-in ZipSigner.

Quick Start:

Desktop / PC:
1. pip install -r requirements.txt
2. Put fonts in Fonts/ subdirectories (Sans/, Monospace/, Serif/, Bengali/).
3. Run: python build.py
4. Flash generated ZIP from dist/ in Magisk, KernelSU, or APatch!

Termux (On-Device):
1. unzip MFFMv14-Source-Template.zip -d ~/MFFMv14 && cd ~/MFFMv14
2. Put fonts in Fonts/ subdirectories.
3. Run: sh termux-build.sh
