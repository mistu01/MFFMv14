# MFFMv14 — Universal Android Font Module Builder
Version: 2026.09.07

Turn any font into a flashable module for Magisk, KernelSU, and APatch — on your PC or directly on your phone using Termux!

━━━━━━━━━━━━━━━━━━━━━━
✨ What's New
━━━━━━━━━━━━━━━━━━━━━━

🕒 Smarter Centered Clock Colon
• Deeply inspects your font to detect any existing centered colon features automatically.
• If your font already has one, MFFM leaves it intact and keeps your config file clean without redundant settings.

📊 Clearer On-Screen Installation Progress
• No more vague installer messages! The screen now clearly shows each feature as it processes, with straightforward success ([OK]) or warning ([!]) status indicators.

🏷️ Live Active Feature Badges
• Your root manager (Magisk, KernelSU, APatch, MMRL) now lists active features directly in the module description (e.g. `[Active: Centered Colon, Tabular Digits, Metrics: compact]`).

📏 Compact Metrics by Default
• Font vertical metrics now default to `compact` (classic tight FFIX3), keeping status bars and notifications neat and compact without unnecessary vertical padding.

🔤 Better Font Selection & Layout Rules
• Always prefers upright regular font faces over italics.
• Contextual clock colon matching now seamlessly handles asymmetric spaces (`12: 30` and `12 :30`).

🚀 How to Build & Use
━━━━━━━━━━━━━━━━━━━━━━

Option 1: Build on PC
1. Put your font files in Fonts/Sans/ (Monospace, Serif, and Bengali folders optional)
2. Run: python build.py
3. Flash the generated ZIP from dist/ in Magisk / KernelSU / APatch

Option 2: Build on Android (Termux)
1. Extract MFFMv14-Source-Template.zip into Termux
2. Put your fonts into Fonts/Sans/
3. Run: sh termux-build.sh (compiles and flashes automatically)

Option 3: Applying Extra Fonts On-Device
1. Flash mffm-runtime-*.zip once in your root manager
2. Drop any Bengali, Serif, or Monospace fonts into /sdcard/MFFM/<Family>/
3. Reflash your font module — it will scan and bundle all weights on-the-fly!
