# MFFMv14 — Universal Android Font Module Builder
Version: 2026.08.27

Turn any font into a flashable module for Magisk, KernelSU, and APatch — on your PC or directly on your phone using Termux!

━━━━━━━━━━━━━━━━━━━━━━
✨ What's New
━━━━━━━━━━━━━━━━━━━━━━

📦 Standalone MFFM Runtime Module
• No need to install Termux or set up pip just to flash fonts with extra languages/weights! Flash the `mffm-runtime` module once, and your phone will handle all on-device font scanning, metrics fixing, and TTC weight bundling automatically during module installation.

🛡️ Google Font Update Blocker
• Stops Google Play System updates from silently reverting your custom fonts.
• Runs quietly in the background at boot.
• Includes a handy one-tap "Action" button in KernelSU / APatch / MMRL to immediately restore your fonts without rebooting.

🎨 Better Font & Multi-Language Support
• Smarter weight detection: reads actual font weights directly from the font binary, so any filename works (even hashed cache names).
• Fixed monospace and serif font priority so your code and text fonts don't clash.
• Full variable font tuning: customize weights and widths in /sdcard/MFFM/*.conf.
• Centered clock colons (12:30) and OpenType feature freezing (slashed zeros, custom alternates).

🧹 Automatic Storage Cleanup
• Runtime installer automatically cleans up its heavy package files after extraction, saving internal phone storage.

🚀 How to Build & Use
━━━━━━━━━━━━━━━━━━━━━━

Option 1: Build on PC
1. Put your font files in Fonts/Sans/ (Monospace, Serif, and Bengali folders optional)
2. Run: python build.py
3. Flash the generated ZIP from dist/ in Magisk / KernelSU / APatch

Option 2: Build on Android (Termux)
1. Extract MFFMv14-Source-Template.zip into Termux
2. Put your fonts into Fonts/Sans/
3. Run: sh termux-build.sh (compiles and flashes automatically)

Option 3: Applying Extra Fonts On-Device
1. Flash mffm-runtime-*.zip once in your root manager
2. Drop any Bengali, Serif, or Monospace fonts into /sdcard/MFFM/<Family>/
3. Reflash your font module — it will scan and bundle all weights on-the-fly!
