# MFFMv14 — Universal Android Font Module Builder
Version: 2026.08.27

Turn any font into a flashable module for Magisk, KernelSU, and APatch — on your PC or directly on your phone!

━━━━━━━━━━━━━━━━━━━━━━
✨ What's New
━━━━━━━━━━━━━━━━━━━━━━

📱 No More Termux Required
• Flash the new MFFM Runtime module once, and your phone can now handle all font installations and weight bundling automatically.

🛡️ Google Font Update Blocker
• Stops Google Play System updates from silently reverting your custom fonts.
• Runs quietly in the background at boot.
• Includes a handy one-tap "Action" button in KernelSU / APatch / MMRL to immediately restore your fonts without rebooting.

🎨 Better Font & Multi-Language Support
• Smarter font detection: reads actual font weights even if filenames are random or encrypted cache names.
• Fixed monospace and serif font priority so your code and text fonts don't clash.
• Full variable font tuning: customize weights and widths in /sdcard/MFFM/*.conf.
• Centered clock colons (12:30) and OpenType feature freezing (slashed zeros, custom alternates).

🧹 Automatic Storage Cleanup
• Installation files clean up after themselves automatically, saving internal phone storage.

🚀 Quick How-To
━━━━━━━━━━━━━━━━━━━━━━

Option 1: Build on PC
1. Put your font files in Fonts/Sans/ (Monospace, Serif, and Bengali folders optional)
2. Run: python build.py
3. Flash the generated ZIP in dist/ via Magisk / KernelSU / APatch

Option 2: On-Device (Recommended)
1. Flash mffm-runtime-*.zip once in Magisk / KernelSU / APatch
2. Flash any MFFMv14 font module — it will automatically configure everything!

Add Extra Fonts Later:
• Drop any Bengali, Serif, or Monospace fonts into /sdcard/MFFM/<Family>/ and simply reflash the module. Any filename works!
